Jellyfin Discovery 0.7.0 and the independently installable Jellyfin Request Hub:

Discovery (0.7.0):
- Oscars Season Subpage (`#/home?fxOscars=1`): dedicated Dark Champagne/Obsidian, Gold & White Academy Awards hub accessible from a seasonal **Oscars** tab in the top navigation bar (and mobile overflow drawer) whenever enabled and inside the configured date window.
- Pure Oscars Hero Banner: full-bleed bespoke obsidian-and-gold Oscars backdrop transitioning seamlessly into the warm obsidian-gold grain background, paired solely with a crisp gold **THE OSCARS** logo (no movie synopsis, ratings, Play, or More Info clutter).
- Gold Statuette Category Rails: all 24 official Academy Award categories (including Best Casting) pre-populated with the 98th Academy Awards nominees; every category displays a gold Oscar statuette icon in place of the red bar and expands to a full poster grid on click.
- Owned & Requestable Nominees: nominated films already in your Jellyfin library open straight to their details page (with a gold watched checkmark once played); undownloaded nominees appear subtly dimmed with a gold **Request** badge and open the themed Request Hub dialog right in place.
- Plugin Admin Studio (`Dashboard -> Plugins -> Jellyfin Discovery`): toggle Oscars on/off, schedule optional Start/End dates, customize the header tab title, upload or reset custom Hero Banner & Logo assets (PNG/JPEG/WebP, static SVG for logo), edit/reorder/add categories and nominees via unified Library + TMDb search, and import/export yearly nominee JSON files.

Request Hub (0.7.0):
- Version parity release with Jellyfin Discovery 0.7.0.
