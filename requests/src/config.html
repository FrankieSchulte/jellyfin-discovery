Request Hub

Connect a Jellyseerr server so signed-in Jellyfin users can browse and request movies and series inside Jellyfin. Every Jellyfin user must be explicitly mapped to their own Jellyseerr user ID.

Jellyseerr Connection

Configure your internal Jellyseerr URL and server-side API key. The API key stays on the Jellyfin server and is never sent to browsers.

User Mappings

Map each Jellyfin account to its corresponding numeric Jellyseerr user ID. Never map regular users to an administrator account.
